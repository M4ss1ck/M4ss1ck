## 🚀 Featured Work

### 🔹 Kaont  
Minimalist, keyboard-first personal finance desktop application.  
Fully offline, zero cloud dependency, designed for long-term dependable use.  

**Stack:** Tauri · React · PostgreSQL / SQLite  

---

### 🔹 Maibuk  
Cross-platform writing application for authors.  
Focused on clean UX, structured writing, and distraction-free drafting.  

**Stack:** Tauri · React · TypeScript  

---

### 🔹 Telegram OBS Overlay  
Real-time Telegram-to-OBS overlay generator.  
Enables streamers to display live Telegram messages directly inside OBS scenes.  

**Stack:** TypeScript · WebSockets · Frontend Overlay Rendering
